타닥싱크 체험판 (맥 · 로그인 없음 · 10회 · Whisper base)
================================================

이 폴더는 윈도우 체험판과 별개입니다.
구글 로그인, 코인, 계정 연동은 없습니다.

■ 실행
  1. zip을 받은 경우 압축을 꼭 풉니다. (압축 안에서 바로 실행하지 마세요)
  2. 폴더 안의 「타닥싱크 체험 실행.command」를 더블클릭합니다.
  3. 맥이 확인되지 않은 개발자라고 막으면, 파일을 우클릭한 뒤 「열기」를 누릅니다.
  4. 처음 실행만 설치가 조금 걸립니다. 두 번째부터는 바로 창이 뜹니다.
  5. Python 3가 없으면 python.org 또는 Homebrew로 설치한 뒤 다시 열어 주세요.

  터미널에서 직접 실행할 때:
  cd tadaksync-trial-mac
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  python3 run.py

■ 사용 방법
1. 캡컷 맥 버전이 설치되어 있고, 자막을 넣을 초안이 있어야 합니다.
2. 자막을 넣을 프로젝트는 캡컷에서 닫아 둡니다.
3. python3 run.py 로 창을 엽니다.
4. 초안을 고르고 [전문 인식 시작]을 누릅니다.
5. 인식된 전문에서 Enter로 줄을 나눕니다. (한 줄 = 자막 하나)
6. [자막 블록 만들기] 후 스타일을 고르고 [캡컷 프로젝트에 삽입]을 누릅니다.
7. 캡컷에서 해당 초안을 다시 열어 확인합니다.

■ 제한
· 이 Mac 계정에서 성공적인 삽입 기준 기본 10회
· 10회를 모두 쓰면 퀴즈가 나옵니다. 정답을 맞힐 때마다 10회가 추가됩니다.
· 음성인식 모델은 Whisper 2단계(base). 첫 실행 시 모델 다운로드가 필요할 수 있습니다.
· 줄 나누기는 엔터로 직접 나누기만 됩니다.
· 프로그램을 실행하면 Google Chrome(있으면)으로 https://vcml.kr 이 함께 열립니다.
