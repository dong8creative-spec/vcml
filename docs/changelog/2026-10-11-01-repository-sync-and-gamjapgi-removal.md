## 감잡기 강의 삭제

삭제한 강의는 동일 제목의 두 문서다.

- 비공개 구버전: `프리미어-프로-입문-감잡기`
- 공개본: `프리미어-프로-입문-감잡기-2`

삭제 범위:

- 강의 2건, 챕터 2건, 수강 3건, 후기 2건, 기대평 3건
- 주문 3건(금액 모두 0원), 쿠폰 7건, 수강코드 19건, 선물 이벤트 설정 1건, 진도 4건
- Firestore 문서 총 46건, 전용 이미지 12개

삭제 전 문서와 이미지 복구 백업을 로컬에 보관했다. 수강생 정보·주문 상세·인증 파일·백업은 공개 GitHub에 포함하지 않는다. 문서 버전 조건을 적용한 원자적 Firestore 배치 삭제 후 이미지도 삭제했다. 다른 강의가 해당 이미지를 참조하지 않는지 먼저 확인했다.

## 검증

- Firestore: 대상 문서 부재, 나머지 강의 4개의 ID 유지 확인.
- Storage: 삭제한 이미지 12개의 부재 확인.
- 로컬 및 `https://vcml.kr`: 강의 목록과 홈페이지에서 감잡기 부재 확인, 두 상세 URL 모두 HTTP 404 확인, 사이트맵에서 관련 URL 부재 확인.
- 기존 무료 다운로드 단위 테스트 3개 통과(로컬 동기화 후 실행).

## Git 커밋의 범위

강의 삭제는 운영 Firestore/Storage에 직접 적용된 데이터 작업이다. 이번 커밋은 이 작업 이력과 현재 인수인계 상태를 기록한다. DB 내용이나 삭제 실행 도구는 포함하지 않는다. 소스·시드 카탈로그에 감잡기 항목이 없어 코드 수정은 필요하지 않았다. 외부 스마트스토어 상품은 이 웹사이트 삭제 범위에 포함되지 않았다.

`HANDOFF.md`에서 이동 전 경로와 과거 Git 오류 안내를 바로잡고 현재 작업 상태를 기록했다. main 보호 설정, Pages, 과거 TadakSync2 워크플로는 이번 작업에서 변경하지 않았다.
