# 타닥클래스 목소리 기준

영상편집을 처음 시작하는 사람이 읽었을 때, 기능 설명서가 아니라 **먼저 해본 사람이 옆에서 알려주는 말**처럼 들려야 합니다.

## 세 가지 원칙

### 1. 기능보다 마음을 먼저

"무엇을 하는 프로그램인가"보다 "왜 만들었는가"를 먼저 말합니다.

- 나쁨: 캡컷 PC 프로젝트의 음성을 인식해 자막을 만들고, 캡컷 캡션 트랙에 바로 넣는 프로그램입니다.
- 좋음: 자막 하나하나 옮겨 적다가 밤새운 적 있으시죠. 그 시간을 좀 줄여드리고 싶어서 만들었어요.

### 2. 실패해도 괜찮다고 말해주기

안 되는 상황을 사용자 잘못으로 들리지 않게 씁니다. 되돌릴 수 있다는 걸 알려줍니다.

- 나쁨: 오류가 발생했습니다.
- 좋음: 잠깐 문제가 생겼어요. 다시 한 번 눌러주시면 됩니다.

### 3. 한 화면에 할 일은 하나

버튼을 늘리는 대신 다음에 할 일 하나만 크게 보여줍니다. 세부 옵션은 필요한 사람만 찾아가게 둡니다.

## 쓰지 않을 표현

기술 용어와 사무적인 표현은 초심자에게 벽이 됩니다.

| 쓰지 않음 | 대신 |
| --- | --- |
| 경량 구성, 호환성 검증 | 먼저 가볍게 써보기 |
| 종량제, 차감, 미차감 | 쓴 만큼, 남은 만큼 |
| 게이트, 엣지, Admin | (사용자 화면에 노출 금지) |
| ~에 실패했습니다 | 잠깐 안 됐어요 / 다시 해볼까요 |
| 이용할 수 없습니다 | 지금은 준비가 조금 더 필요해요 |
| ~해야 합니다 | ~하시면 돼요 |
| 등록된 ~이 없습니다 | 아직 ~이 없어요 |

## 문장 규칙

- 종결은 `~어요` / `~해요` 중심. 딱딱한 `~합니다`는 법정 고지에만 남깁니다.
- 한 문장은 40자 안쪽. 두 가지를 말해야 하면 문장을 나눕니다.
- 숫자와 단위 나열(30초/1코인 같은 표기)은 문장으로 풀어 씁니다.
- 횟수·수량은 아라비아 숫자로 씁니다. `열 번`이 아니라 `10번`, `한 장`이 아니라 `1장`.
- 파일 이름(`run.bat`)처럼 점(.)이 들어가는 말은 줄 가운데에서 끊지 않습니다.
- 사용자를 주어로 두고 씁니다. "시스템이 처리합니다"가 아니라 "이렇게 하시면 돼요".

## 전후 예시

**타닥싱크 테스트 버전**

- 전: 테스트 버전은 정식판의 품질을 단순화한 체험 상품이 아니라, 내 PC와 캡컷 프로젝트에서 핵심 작업 흐름이 안정적으로 작동하는지 확인하는 경량 구성입니다.
- 후: 먼저 편하게 한번 써보세요. 내 컴퓨터에서 잘 돌아가는지, 손에 맞는지 보시라고 준비했어요. 마음에 안 들면 폴더만 지우면 됩니다.

**코인 안내**

- 전: 인식 30초/1코인 · 줄나눔 자동 1 / 엔터 2 · 번역 20초/10코인
- 후: 1분짜리 영상 자막을 만들면 2코인쯤 써요. 처음 오시면 10코인을 드리니 넉넉하게 연습해 보세요.

**빈 목록**

- 전: 등록된 공지사항이 없습니다.
- 후: 아직 알려드릴 소식이 없어요. 준비되면 가장 먼저 알려드릴게요.

**권한 없음**

- 전: 이용할 수 없습니다
- 후: 지금은 준비가 조금 더 필요해요

## 예외

이용약관, 개인정보처리방침, 환불정책, 청소년보호정책의 본문은 법적 효력이 있으므로 **문구를 바꾸지 않습니다.** 해당 페이지의 안내 문단(히어로)까지만 부드럽게 다듬습니다.
