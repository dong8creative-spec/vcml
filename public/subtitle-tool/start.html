설치하는 법

어려운 건 없어요. 파일을 받아서 압축을 풀고 아이콘 하나만 누르면 되고, 순서대로 따라오시면 돼요.

먼저 써보실 때

바로 결제하시라고 하면 부담스러우시죠. 그래서 먼저 써보실 수 있게 준비했어요. 내 컴퓨터에서 잘 돌아가는지만 편하게 확인해 보세요.
1
파일 받기

먼저 써보기에서 구글 계정으로 들어오신 뒤 버튼을 눌러주세요. 받은 파일은 압축을 꼭 풀어주세요. 압축 안에서 바로 실행하면 잘 안 돼요.

2
run.bat 2번 누르기

압축을 푼 폴더 안에 있는 run.bat을 2번 누르면 창이 열려요. 파이썬 같은 건 따로 설치하지 않으셔도 되고, 필요한 게 안에 다 들어 있어요.

3
한 번 만들어 보기

영상 고르기 → 목소리 알아듣기 → 엔터로 줄 나누기 → 캡컷에 넣기까지 한 바퀴 돌려보세요. 작업할 캡컷 영상은 닫아 두신 뒤 시작해 주세요. 열려 있으면 자막이 안 들어가요.

정식 버전을 쓰실 때

4
파일 받고 압축 풀기

정식 버전에서 파일을 받아 원하는 폴더에 압축을 풀어주세요.

5
TadakSync2 실행하고 로그인

폴더 안의 TadakSync2를 누르고, 「구글 계정으로 시작하기」를 눌러주세요. 윈도우가 처음 보는 파일이라 경고를 띄우면, 아래 「잘 안 될 때」를 보시면 돼요.

6
이 컴퓨터랑 연결하기

프로그램에 번호가 뜨면 「브라우저에서 연동」을 누르시면 연결 화면으로 넘어가고, 버튼 한 번만 누르면 끝이에요. 한 계정에 컴퓨터 1대만 연결되고, 다른 컴퓨터에서 연결하시면 알아서 옮겨져요.

잘 안 될 때

영상 목록이 안 보여요
프로그램에서 「폴더 지정」을 누르고 캡컷 폴더를 직접 골라주시면 됩니다.

처음 자막 만들 때 한참 기다려요
목소리를 알아듣는 파일(약 3GB)을 처음 한 번만 받아둡니다. 그다음부터는 빨라져요.

윈도우가 실행을 막아요
프로그램이 고장난 게 아니에요. 처음 보는 파일이라 윈도우가 한 번 물어보는 경우가 많아요. 「추가 정보」→「실행」을 눌러 보시고, 그래도 안 되면 파일을 우클릭해서 속성 → 보안 → 차단 해제를 눌러 주세요. 보안 설정을 억지로 끄지는 마세요. 말씀해 주시면 같이 찾아볼게요.
